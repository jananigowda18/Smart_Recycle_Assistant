# ReCycle AI – Smart Recycling Assistant

## Project Description

ReCycle AI is an AI-powered waste classification system designed to help users identify different types of waste and dispose of them correctly. The system uses a trained machine learning model to classify uploaded waste images into categories such as plastic, paper, cardboard, metal, glass, batteries, biological waste, clothes, shoes, and general trash.

The application provides information about the detected waste, its disposal category, whether it can be recycled, the recommended bin or collection point, and proper disposal methods. Users can upload an image or capture a photo using their camera to analyze the waste.

The frontend is developed using HTML, CSS, and JavaScript, while Python Flask connects the user interface to the trained AI model.

## Problem Statement

Improper waste segregation and incorrect disposal of recyclable and hazardous materials contribute to environmental pollution and reduce recycling efficiency. People may find it difficult to identify different waste types and determine the appropriate bin or disposal method for each item. Traditional waste segregation often depends on manual identification, which can lead to mistakes and the mixing of recyclable, biodegradable, and hazardous waste. Therefore, there is a need for a simple, AI-powered system that can identify waste from images and provide clear guidance on its category, recyclability, recommended bin, and safe disposal method.

## Project Objective

The main objective of ReCycle AI is to simplify waste segregation using artificial intelligence. It aims to improve waste identification, encourage proper recycling practices, reduce incorrect disposal, and increase environmental awareness by providing users with clear and practical waste disposal recommendations.
